寫給爸媽的

麥塊入門指南

孩子整天在玩 Minecraft、看麥塊影片，你想知道那到底有什麼好玩的——
更想知道，自己能不能一起進去。

吸引力 為何看影片 怎麼融入 遊戲時間 兩種模式 怎麼開始玩 新手攻略 資源

麥塊的吸引力在哪

沒有人規定你要做什麼

麥塊沒有通關條件、沒有分數、沒有排名。孩子生活裡幾乎所有事——課表、作業、才藝班——目標都是別人訂的。麥塊是少數他們百分之百掌控的世界。

這個「自主權」比畫面好看重要一百倍。

我做的東西，真的存在

蓋一棟房子，它就在那裡，明天登入還在。這種創造之後留下痕跡的滿足感，對孩子非常強烈。

表面是積木，底層是工程

紅石電路其實就是邏輯閘，玩到深處有人用麥塊做出計算機。自動化農場、刷怪塔、物品分類系統，都是真的系統設計。

很多孩子是從紅石開始理解「條件」「迴圈」「訊號」的。

這是他們的遊樂場

多人伺服器、小遊戲（起床戰爭、空島、躲貓貓）、跟同學約好一起蓋。這是社交，不只是遊戲。

為什麼不玩，卻一直看 YouTube？

這點最常被大人誤解成「看別人玩很浪費時間」。實際上分成幾種完全不同的需求：

  • 學技巧 — 紅石教學、建築教學。本質上等於看教學影片
  • 看自己做不到的內容 — 極限生存、大型企劃、模組整合包
  • 陪伴與幽默 — 這類影片的主角其實是實況主的個性，遊戲只是背景。功能上接近我們以前聽廣播

幾個值得認識的國外頻道

既然要看，看英文的。孩子為了看懂內容會主動去理解英文，這是最無痛的語言環境——比背單字有效得多。而且國外的技術類頻道講得比較深。

頻道類型為什麼值得看
Mumbo Jumbo 紅石工程 全世界最知名的紅石頻道，訂閱數近千萬。把電路原理講得像在拆玩具，孩子看他的影片等於在學邏輯設計
Grian 建築 建築教學的代表人物。從房子的比例、材質搭配到細節裝飾，是真的在教設計
Hermitcraft 多人企劃 一群創作者共用同一個世界，各自拍自己的視角。Mumbo 和 Grian 都在裡面。適合看「合作與衝突怎麼處理」
DanTDM 綜合娛樂 老牌大台，以家庭友善著稱。語速中等，適合已經有點英文基礎的孩子
Stampy 低齡入門 以貓的角色演出，語速慢、用詞簡單、完全無暴力語言。小學低年級的英文入門首選

三個實用提醒

先自己看一集。頻道的風格會隨時間改變，早年家庭友善的創作者後來轉向其他題材的例子不少。花十分鐘確認，比事後補救容易。

打開英文字幕。YouTube 的自動字幕已經夠準。聽不懂的地方能看到拼字，學習效果差很多。

從紅石或建築類開始。這類影片有明確的知識內容，孩子看完會想動手做；純娛樂類則容易一集接一集停不下來。

怎麼融入孩子——最有效的三招

  1. 請他們當老師

    這是威力最大的一招。問一句「這個紅石是怎麼運作的？」然後真的聽完。孩子很少有機會在大人面前當專家，那個成就感會讓他們主動想分享更多。

  2. 進去玩，而且玩得爛

    開個區域網路世界跟他們一起生存。你會挖到岩漿、會被苦力怕炸掉、會迷路——這些全是加分。他們會樂於保護你、指揮你、幫你蓋房子。

    你不是在「監督」，你是隊友。

  3. 陪看一集，記住名字和梗

    挑他們最愛的一個頻道，陪看完整一集，記住實況主的名字跟口頭禪。之後在餐桌上引用一次，效果勝過十次「你今天在幹嘛」。

幾個能讓你立刻加分的提問

  • 「你玩的是 Java 版還是基岩版？」——問出這句，孩子會知道你有做功課
  • 「你今天蓋了什麼？」——而不是「你玩多久了？」
  • 「你最想蓋但還沒蓋成的是什麼？」——這題常會打開話匣子

兩個地雷

別把麥塊當談判籌碼。「不寫作業就不能玩」會讓他們把你和這件喜歡的事放在對立面。

時間管理要用自然斷點。麥塊沒有回合，隨時中斷等於丟進度，所以「還有五分鐘」會引發對抗。改成「蓋完這段」或「回到床邊存檔就下線」，衝突會少很多。

遊戲時間怎麼管

如果電腦是這幾天才到的——第一天不算數。新電腦加上麥塊，玩很久是必然的，那是新鮮感不是習慣。這時候立刻上規範，他會把「新電腦」和「被限制」綁在一起。

先修正一個常見誤區

Google Family Link 管不到 Windows 電腦

Family Link 管的是 Google 帳號與 Android／ChromeOS 裝置。Windows 筆電要用另一套系統。

而麥塊本來就綁微軟帳號，所以正確的工具是 Microsoft Family Safety（family.microsoft.com）——它能精準管到「Minecraft 這個 App 玩多久」，不是只能管整台電腦開關機。

設定路徑

  1. 到 family.microsoft.com，用你的微軟帳號登入

  2. 新增家庭成員 → 輸入孩子的微軟帳號（就是玩麥塊那個）

  3. 找到他的名字 → 切到 Windows 分頁

  4. 選「應用程式與遊戲」→ 開啟限制

  5. 點 Minecraft → 設定每天可玩多久、哪幾天適用、可玩的時段

它能做到三種層次，但建議只先用最後一種：

層次做什麼建議
裝置時間整台電腦幾點到幾點能開❌ 太粗暴
App 時間麥塊每天玩幾小時⚠️ 備用
活動報告只看不管，知道他玩了多久✅ 先開這個

為什麼建議先不要開限制

因為麥塊沒有回合。系統時間到就強制斷線，對麥塊玩家是最糟的體驗——他可能正在挖礦的路上、蓋到一半、剛找到鑽石還沒回家存檔。

被硬斷的那個瞬間，他學到的不是「該休息了」，是「電腦會突然背叛我」。

先試這三個

用自然斷點，不用時鐘

不要說「還有十分鐘」，說「回到床邊存檔就下線」或「這個礦挖完」。

同樣是結束，一個是被剝奪，一個是完成。

開始前先問他要做什麼

「你今天想做什麼？」讓他自己講出目標——「我要蓋一個自動農場」。

有目標就有終點，他自己會知道哪裡是段落。

你進去玩

一起玩四十分鐘再一起下線，比你在旁邊倒數有用得多。

你不是在監督，你是隊友。

什麼時候才該開技術限制

當約定反覆失效時——不是第一天，是連續兩三週講好了還是拖。

那時候再開，而且要先告訴他為什麼開、開多久，不要無聲上鎖。被發現偷偷設限，損失的信任比多玩那半小時貴得多。

時間不要設太緊

八歲一次專注大約 30–40 分鐘。一天給 60–90 分鐘反而比 30 分鐘容易遵守——太緊的限制會讓他把每一分鐘都花在「怕被切斷」的焦慮上，反而更難停下來。

今天最該做的一件事：陪他玩一次。看看他在蓋什麼、問他為什麼那樣蓋。你會同時得到他玩多久的實際感受，以及一個「爸爸對我在做的事有興趣」的訊號——那比任何時間限制都更能影響他明天怎麼安排。

生存模式 vs 創造模式

一句話：生存模式是「玩遊戲」，創造模式是「玩積木」。生存有挑戰、有死亡、有目標；創造沒有規則，只有無限的材料和一片空地。

這兩種模式的差別大到幾乎像兩款不同的遊戲。孩子講「我在生存」跟「我在創造」，指的是完全不同的活動。

完整對照

🗡️ 生存模式 Survival🎨 創造模式 Creative
血量有，會死無敵，摔不死、燒不死
飢餓值有，要吃東西沒有
資源要自己挖、砍、種所有東西無限拿
飛行不能（除非有鞘翅）空白鍵按兩下就能飛
挖方塊要工具、要時間點一下瞬間消失
怪物晚上會來殺你會生成，但不會攻擊你
死亡懲罰東西掉一地，要跑回去撿不會死
經驗值／附魔有沒必要
成就可以解不會累積

為什麼孩子兩種都愛

生存：我靠自己活下來了

第一天什麼都沒有，赤手空拳打樹、做工具、挖洞躲怪；第三天有了鐵劍，第十天有了鑽石。從零到有的過程才是核心樂趣。

這也是為什麼直接送他一堆鑽石，反而會毀掉遊戲。

創造：我腦中的東西被蓋出來了

想蓋城堡、蓋船、蓋紅石電梯——不用先挖三天石頭，直接蓋。YouTuber 拍的那些誇張建築，幾乎都是在創造模式完成的。

孩子通常是交替著玩：生存模式玩冒險，創造模式玩建築。

給爸媽的實際建議

  1. 第一次玩，開創造模式。

    不是因為簡單，是因為你需要先熟悉操作。生存模式一開場天就黑了、怪就來了，你連怎麼跳都還不會就會很挫折。花 20 分鐘飛一飛、蓋幾個方塊、按按物品欄，把 WASD 跟滑鼠練順。

  2. 熟悉後，跟孩子一起進生存模式。

    這才是能真正一起玩的地方。分工——他挖礦你蓋房子，或者他當嚮導你當新手。讓他教你是最好的切入點，八歲孩子難得有機會當爸爸的老師，他會超投入。

怎麼切換模式

建立世界時就要打開「允許作弊 / Allow Cheats」，之後才能中途切換。

版本切換方式
Java 版按 T 開聊天欄，輸入 /gamemode creative 或 /gamemode survival
基岩版暫停 → 設定 → 遊戲 → 下拉切換「遊戲模式」

Java 版世界原本沒開作弊也有救：按 Esc → 開啟至區域網路 → 允許作弊：開（僅本次遊戲有效）。

開作弊會關掉成就

一旦開啟作弊，那個世界的成就就不再解鎖。如果孩子在意成就，不要在他的主世界開作弊——另外開一個創造模式的世界給他蓋東西就好。

順帶一提，其實有四種模式

模式說明
🗡️ 生存標準玩法
🎨 創造無限資源、可飛行、無敵
🧭 冒險 Adventure不能隨意破壞方塊，給地圖作者用的
💀 極限 Hardcore生存模式 +死一次世界就毀了，Java 版限定

先別讓孩子碰極限模式

YouTube 上「100 天極限模式」系列就是這個，是高手在玩的。八歲孩子存了幾十小時的世界一次死光，會哭很久。

怎麼開始玩

麥塊不是網頁遊戲，要下載安裝，而且一定需要帳號（微軟帳號）。

先搞懂：兩個版本

Java 版基岩版 Bedrock
平台只有電腦（Win / Mac / Linux）手機、平板、Switch、PS、Xbox、Windows
模組超多，MOD 生態全在這幾乎沒有，只有官方市集
跟誰一起玩只能跟 Java 版可跨裝置互連
YouTube 影片多半是✅ 這個部分小遊戲伺服器

Windows 電腦的最佳選擇：官網有賣「Minecraft: Java & Bedrock Edition for PC」同捆包，一次購買兩個版本都有。手機版要另外在 App Store / Google Play 買，和 PC 版是分開的兩筆。

帳號怎麼辦

必須有微軟帳號，2023 年之後 Mojang 帳號已全面整併。給孩子的正確做法是：

  1. 用你的微軟帳號建立 Microsoft Family Safety 家庭群組（你當家長）

  2. 在群組裡幫孩子建立兒童帳號（未滿 13 歲需要家長同意，系統會引導）

  3. 遊戲買在孩子的帳號上

這樣做你會拿到遊戲時間限制、消費額度控管、活動報告，而且孩子有自己的角色和世界。買在你帳號上雖然省事，但沒有家長控制，你們也沒辦法同時上線一起玩。

兩個孩子想同時玩 ＝ 需要兩個帳號、兩份遊戲。授權綁帳號，無法共用。

一個很多家長會卡住的雷

買完裝好，孩子想跟同學連線時跳出「無法進行多人遊戲」——這不是遊戲壞掉，是微軟帳號的 Xbox 隱私設定預設把兒童帳號的線上遊玩關掉了。

要到微軟帳號的隱私設定裡，把「可以參加多人遊戲」「可以和其他人交流」打開。這個開關同時也是你控管線上社交的地方，值得先了解它在哪。

想先試玩不花錢

  • classic.minecraft.net — 2009 年的初代版本，瀏覽器直接玩，免費、免帳號。只有蓋方塊，沒有生存要素，但可以先感受一下
  • 官方試玩版 — Java 版約 100 分鐘遊戲時間，可以確認電腦跑不跑得動

購買步驟

  1. 到 minecraft.net（只認這個官網）

  2. 用要擁有遊戲的帳號登入

  3. 選 PC 同捆包購買

  4. 下載 Minecraft Launcher，登入後就能安裝、啟動

價格不在這裡列數字——台灣區定價和促銷會變動，各平台也不同，請以官網登入後顯示的為準。

務必小心盜版與詐騙

網路上有大量「麥塊免費下載」「便宜帳號」的網站，全是盜版或盜來的帳號——買來的帳號隨時會被回收，且常挾帶惡意程式。

認明 minecraft.net、App Store、Google Play、各主機官方商店，其他一律不要碰。

新手攻略

第一晚 SOP（新手最容易死在這）

麥塊天黑就出怪，第一天大約 10 分鐘要完成這一串：

  1. 徒手打樹 → 拿木頭 → 合成木板 → 做工作台

  2. 工作台做木鎬 → 挖石頭（至少 20 顆）

  3. 石頭做石鎬、石斧、石劍

  4. 挖到煤炭 → 木棒 ＋ 煤 ＝ 火把

  5. 打羊拿羊毛（3 羊毛 ＋ 3 木板 ＝ 床）

  6. 挖進山壁封住洞口，或蓋個小土屋，睡覺跳過夜晚

床非常關鍵：睡覺不只跳過夜晚，還會設定重生點。沒床死掉會被丟回出生點，可能離家幾千格。

裝備進程

木 → 石 → 鐵 → 鑽石 → 獄髓 Netherite

前三階很快，鑽石是分水嶺，獄髓要去下界找「遠古遺骸」。

挖鑽石的高度（1.18 改版後）：世界最底是 Y = −64，鑽石在 Y = −59 附近最密集。挖到那個深度後開一條長長的水平隧道，比亂挖有效率得多。按 F3 可以看座標（Java 版）。

兩個鐵則

不要直直往下挖——會掉進岩漿或深洞，這是最經典的死法。

隨身帶水桶——可以澆熄岩漿，也能在高處放水防摔。

聽懂孩子在說什麼

這幾個詞你知道了，餐桌對話就接得上：

名詞是什麼
苦力怕 Creeper綠色的，會無聲靠近然後爆炸。麥塊的招牌
終界使者 Enderman高瘦黑色，盯著牠的眼睛看牠會暴怒
紅石 Redstone遊戲內的電路系統，能做自動門、電梯、計算機

中期目標（有方向才不會膩）

  1. 穩定的家 ＋ 箱子分類 — 麥塊真正的敵人是「東西太亂」

  2. 鐵農場／作物農場 — 資源自由的起點

  3. 下界探險 — 拿烈焰棒、找遠古遺骸

  4. 村民交易 — 用綠寶石換附魔書，比自己附魔穩定太多

  5. 打終界龍 — 名義上的通關，但多數玩家打完才真正開始玩

攻略去哪查

  • Minecraft Wiki（中文）

    中文版完整度極高，合成表、生成高度、機制細節都在這，比任何影片準確。查東西優先用它。

  • Minecraft 官方網站

    唯一的正版購買管道，也是下載 Launcher 的地方。

  • Minecraft Classic

    2009 年初代版本，瀏覽器免費玩、免帳號。

  • YouTube

    建築和紅石教學看影片比看文字好懂。搜「麥塊 生存 新手」「紅石 教學」。

  • 遊戲內的「進度 Advancements」

    官方內建的引導系統，照著解就是一條主線。

最後一個建議

別把攻略讀完再上場。

你如果讀完攻略進去，什麼都會，孩子就沒有教你的機會了——那才是最可惜的。

建議你只記「第一晚 SOP」和那張名詞表，其他全部留白，進去之後大方問：
「這個怎麼弄？」「為什麼牠會爆炸？」
